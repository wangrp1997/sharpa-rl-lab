# 探索开关的活体试验

**日期：** 2026-09-24

每个控制周期只解当前这一步。下一周期用新的指尖力和关节角再解一次。这里没有多步预测，不把这一步叫做模型预测控制。

控制器只用指尖力、接触雅可比、指尖位置和物体姿态。物体质量、材料摩擦和仿真里的真实摩擦系数只写进诊断日志，不进入求解。日志里的关节角和物体位姿不能再写回仿真：接触状态不在这 29 个数里，写回去圆柱会被推出去。

## 现在实际在解的式子

承载手指是指尖力大于 \(0.5\,\mathrm{N}\) 的那些。尚未标成“不传递切向”的承载手指构成集合 \(\mathcal F\)。其中载荷最弱、且还没有探针标签的一根记为 \(d\)。

两种假设：

- \(H_{+}\)：\(\mathcal F\) 里每根手指都把切向运动传到圆柱。
- \(H_{-}\)：\(d\) 不传递，其余手指传递。

对一个假设里的传递集合 \(\mathcal T\)，求关节增量 \(u\in\mathbb R^{22}\) 和绕圆柱轴的偏航增量 \(\psi\)：

\[
\begin{aligned}
J_{f,a} u - t_{f,a}\,\psi &= 0
&& f\in\mathcal T,\ a\in\{x,y,z\} \\
8\,\psi &= 8\times 0.01 \\
0.05\,u_j &= 0
&& j\in\mathrm{cols}(\mathcal T)
\end{aligned}
\]

\(J_{f,a}\) 是该指尖接触雅可比的第 \(a\) 行，列只取这根手指的驱动关节。\(t_f=\omega\times(p_f-c)\) 是指尖相对物体中心、沿圆柱轴 \(\omega\) 的切向杠杆。任务行把 \(\psi\) 拉向 \(0.01\,\mathrm{rad}\)。关节阻尼是 \(0.05\)。最小二乘解出后，\(u\) 夹在 \(\pm 0.008\,\mathrm{rad}\)。

记两个假设的解为 \(u_{+}\)、\(u_{-}\)。分歧

\[
\mathrm{gap}=\|u_{+}-u_{-}\|_\infty .
\]

开关只在 \(d\) 存在且 \(\mathrm{gap}>5\times 10^{-4}\) 时打开。打开时执行

\[
u=\mathrm{clip}(u_{+}+\Delta u_d,\ \pm 0.008).
\]

\(\Delta u_d\) 只在 \(d\) 的关节上非零，使该指尖沿 \(t_d\) 的单位方向再走 \(4\times 10^{-4}\,\mathrm{m}\)。其余关节保持 \(u_{+}\)，所以这一步仍然带着 \(\psi=0.01\) 的任务。实测 \(|\Delta\psi|>0.002\) 就把 \(d\) 标成传递，否则标成不传递。关掉开关时，即使 \(\mathrm{gap}\) 超过阈值，也执行 \(u_{+}\)，不加 \(\Delta u_d\)、不贴标签。

第一版探针没有加 \(u_{+}\)，只走切向。那个结果留在下面 2026-09-24 的前两节，日志是 `trace.jsonl`。带任务的探针日志是 `trace_gated.jsonl`。

掉落判定是物体高度比试验起点低 \(0.02\,\mathrm{m}\)。

[contact_step_optimization.md](contact_step_optimization.md) 里的约束非线性规划比上面多了任务残差上界、载荷裕度和法向凸包记录。那一道还没有在筛到的手上跑。这次活体循环只解了上面的耦合最小二乘和单指探针。

## 2026-09-24 关掉开关

日志 `logs/live_diag/trace_off.jsonl`。同一种子、同样 256 个环境，再次停在环境 93。停住瞬间的物体位姿、22 个关节角、五指尖位置和五路载荷与打开臂的快照最大差是 0。这是另一次筛选，不是把姿态写回仿真。

## 这一轮能说的和不能说的

把任务加回探针之后，少转的那 \(0.010\,\mathrm{rad}\) 消失了。打开臂停在目标另一侧 \(0.008\,\mathrm{rad}\)，关掉臂停在目标这一侧 \(0.009\,\mathrm{rad}\)。多出来的转角集中在三步附加切向上。

这仍是一只手、一个种子、24 步。两边到目标的距离几乎一样，不能把“打开时姿态更好”写成已经成立的结论，也没有留下要继续加公式的差。质量和摩擦力矩阵仍然没进日志。
